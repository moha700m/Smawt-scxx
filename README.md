# SMAET REC

تطبيق سطح مكتب محلي لنظام Windows 11 بواجهة عربية مبسطة لتسجيل شاشة الكمبيوتر.

## الحالة الحالية — MVP قيد التطوير
- واجهة PySide6 عربية باتجاه RTL.
- معاينة مباشرة للشاشة الأساسية عبر MSS.
- أدوات قلم وتمييز فوق المعاينة.
- تسجيل سطح المكتب إلى MP4 عبر FFmpeg `gdigrab` وH.264 بمعدل 30 إطاراً/ثانية.
- عرض حالة التسجيل ومدته، وفتح مجلد الفيديوهات.
- حفظ وفتح مشاريع JSON وحفظ مجلد الإخراج الأخير.
- لا خادم ويب ولا واجهة تحكم شبكية ولا رفع سحابي. لا يتم فتح منافذ؛ واجهة التحكم تطبيق Windows محلي.

**غير منفذ بعد:** استقبال iPhone عبر USB أو AirPlay، معاينة iPhone، تسجيل الميكروفون أو صوت النظام، اختيار الشاشات والنوافذ، 4K، وأدوات الرسم المتقدمة. لا يعرض التطبيق اتصال iPhone وهمياً.

## المتطلبات
- Windows 11
- Python 3.11 أو أحدث
- FFmpeg يحتوي على `gdigrab` و`libx264` ومضاف إلى PATH

## التشغيل
1. شغّل `install.bat`.
2. ثبّت FFmpeg بشكل منفصل.
3. شغّل `run.bat`.

## بناء نسخة Windows
شغّل `build.bat`. ستظهر حزمة PyInstaller مجلدية غير موقعة داخل `dist/SMAET-REC/`؛ هذه ليست أداة تثبيت MSI/EXE. يجب البناء والاختبار على Windows 11 فعلياً.

## الخصوصية
لا يشغّل التطبيق خادم HTTP ولا يفتح منفذاً شبكياً. التسجيل محلي. إذا أضيف AirPlay مستقبلاً، فسيكون مستقبلاً منفصلاً يحتاج LAN، مع إبقاء أي واجهة تحكم أو API على `127.0.0.1` حصرياً.

راجع `docs/DEVELOPMENT.md` للتفاصيل وحدود النسخة الحالية.
