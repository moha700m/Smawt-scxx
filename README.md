# SMAET REC

A local-first Windows 11 recording studio. The control interface and local API bind to `127.0.0.1` only. Any optional AirPlay receiver is a separate LAN-facing component and must not expose the control API.

## Status
Project scaffold initialized. Hardware capture and recording capabilities are being added incrementally and must be verified on a Windows device.
